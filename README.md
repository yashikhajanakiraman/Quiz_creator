# 🎯 Quizzle

Quizzle is a quiz web application where users can **create their own quizzes**, **play instant AI-generated quizzes**, and also explore and attempt **public quizzes created by other users**.

It is designed to make learning interactive, fast, and personalized — whether you're preparing for exams, practicing concepts, or simply testing your knowledge.

## 🔐 Authentication & User Accounts

Quizzle includes a complete user system with:

- **Sign Up / Login**
- User information stored securely in the database
- Users can access and manage only their own private quizzes

---

## 🧩 Quiz Types in Quizzle

### 1) 📌 User-Created Quizzes
Users can create quizzes with their own:
- Topic / title
- Questions and options
- Correct answers
- Hints *(if added)*

They can also:
- **Edit** their created quizzes
- **Delete** quizzes anytime

---

### 2) ⚡ Instant Quizzes (Gemini Powered)
Quizzle supports **instant quiz generation using Gemini API**.

Users can type a prompt/topic, and the system will:
- Analyze the prompt
- Detect the hidden topic
- Validate whether the topic is suitable for quiz generation
- Generate a quiz instantly based on the prompt

This makes the quiz experience fast and personalized without needing manual quiz creation.

---

## 🌍 Public Quizzes vs 🔒 Private Quizzes

### 🌍 Public Quizzes
- Visible to other users
- Anyone can attempt them
- Labeled clearly as **Public Quizzes**

### 🔒 Private Quizzes
- Only the quiz owner can access and attempt
- Not visible to other users

This separation helps users keep some quizzes personal while sharing others publicly.

---

## ⏱️ Quiz Difficulty Modes (Instant Quizzes)

Instant quizzes include three modes with different question counts and time limits:

- **Easy Mode**
  - ⏳ 10 seconds per question
  - ✅ 5 questions

- **Medium Mode**
  - ⏳ 15 seconds per question
  - ✅ 10 questions

- **Hard Mode**
  - ⏳ 20 seconds per question
  - ✅ 15 questions

---

## ✅ Results & Answer Review

After completing an instant quiz, Quizzle shows a **result section** that includes:
- Final score
- Correct answers for review

This helps users learn instantly from mistakes and improve faster.

---

## 👤 Profile Management

Users can update their profile information within the app to personalize their experience.

---

## 🚀 How to Use Quizzle (Quick Guide)

1. **Sign Up / Login**
2. Choose one option:
   - Create your own quiz
   - Attempt **instant AI-generated quiz**
   - Try **public quizzes**
3. Select mode (Easy / Medium / Hard) for instant quizzes
4. Attempt the quiz within the given time
5. View results and correct answers
6. Manage your quizzes:
   - Edit
   - Delete
   - Set Public / Private (based on the quiz type)
